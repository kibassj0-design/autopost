أفضل أوقات النشر

الأوقات بتوقيت جهازك، وتُعتبر توقيت جمهورك. الأوقات العامة مأخوذة من دراسات كبيرة (Buffer وSprout Social وRivalIQ وLater) ومعدّلة لجمهور عربي، والدراسات نفسها تختلف فيما بينها. لذلك تتعلم الأداة أوقات حسابك من مشاهدات منشوراتك، وتعتمدها بدل العامة حين تجمع ما يكفي.

الحسابات

اربط حساباتك مرة واحدة، والخطوات مكتوبة بجانب كل منصة.

يوتيوب

  1. افتح console.cloud.google.com وأنشئ مشروعا.
  2. APIs & Services ← Library: فعّل YouTube Data API v3.
  3. OAuth consent screen: اختر External، ثم في Audience ← Test users أضف إيميل قناتك.
  4. Credentials ← Create credentials ← OAuth client ID من نوع Desktop app، والصق القيمتين هنا.
الأضمن: في Google Cloud اضغط Download JSON بجانب الـ client أو الـ secret الجديد، واستورد الملف هنا بدل النسخ واللصق.
عند تحذير «لم تتحقق Google من هذا التطبيق»: إعدادات متقدمة ← الانتقال إلى التطبيق. ولكي لا ينتهي الربط كل 7 أيام: Google Auth Platform ← Audience ← Publish app.

انستغرام

  1. حوّل حسابك إلى احترافي (Creator أو Business) من إعدادات تطبيق انستغرام.
  2. افتح developers.facebook.com/apps ← Create App، واختر الاستخدام الخاص بـ Instagram.
  3. داخل التطبيق: Instagram ← API setup with Instagram login ← Add account وسجّل بحسابك.
  4. اضغط Generate token بجانب حسابك، وانسخ التوكن (يبدأ بـ IG) والصقه هنا. الأداة تعرف رقم الحساب وحدها وتجدد التوكن تلقائيا.

الطريقة الأضمن للنشر: الربط عبر فيسبوك

رفع الفيديو المباشر لانستغرام مصمَّم لهذه الطريقة. إذا فشل النشر بالتوكن أعلاه («ProcessingFailedError»)، استخدمها:

  1. اربط حساب انستغرام بصفحة فيسبوك: إعدادات الصفحة ← الحسابات المرتبطة ← Instagram.
  2. في developers.facebook.com/apps ← تطبيقك ← إعدادات التطبيق ← أساسي (App settings ← Basic): انسخ App ID و App secret.
  3. إذا كان لتطبيقك «تكوين» تسجيل دخول فيسبوك للأعمال (رقم يظهر بجانب «معرف التكوين»)، ضعه في الخانة الثالثة، وإلا اتركها فارغة.
  4. اضغط «ربط عبر فيسبوك» ووافق على كل الصلاحيات واختر صفحتك وحساب انستغرام.

تيك توك

  1. افتح developers.tiktok.com/apps ← أنشئ تطبيقا واملأ بياناته.
  2. Add products: أضف Login Kit و Content Posting API، وفعّل Direct Post. في Scopes فعّل video.publish و video.list.
  3. في Login Kit ضع Redirect URI صفحة GitHub Pages الخاصة بمستودعك (مثل https://اسمك.github.io/autopost/)، وضع نفس الرابط هنا بالحرف.
  4. في Sandbox ← Target users أضف حسابك، ثم الصق Client key و Client secret واضغط ربط.
قبل أن يجتاز تطبيقك تدقيق تيك توك، كل ما يُنشر يكون خاصا (تراه أنت فقط).

حفظ المفاتيح والحسابات

الأداة تحفظ نسخة من مفاتيحك وحساباتك المربوطة وإعداداتك تلقائيا خارج مجلد الأداة، وترجعها وحدها إذا حُذف المجلد أو نزّلته من جديد. ويمكنك أيضا حفظ ملف نسخة احتياطية في أي مكان (مثل فلاشة)، واسترجاعه على أي جهاز.

⚠️ ملف النسخة فيه كل مفاتيحك: احفظه عندك ولا ترسله لأحد.
